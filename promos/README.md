# الإعلانات

ارفع هنا صور الإعلانات (من GitHub: Add file ← Upload files)، **أو الأسهل: من تطبيق الإدارة ← المزيد ← الإعلانات** (يختار الاسم الصحيح تلقائياً).

## 1) إعلان مباراة (مع عدّاد تنازلي وزر «شاهد»)

**اسم الملف = موعد الانطلاق بتوقيت بغداد:**

```
2026-10-20_21-45.jpg
2026-10-20_22-00_ريال-مدريد-برشلونة.jpg
2026-10-20_22-00_m1208345.jpg      ← ربط مباشر برقم المباراة (يضعه تطبيق الإدارة)
```

- `2026-10-20` التاريخ، `21-45` الساعة والدقيقة، وما بعدها عنوان اختياري (الشرطات تصبح مسافات).
- يختفي تلقائياً بعد ساعتين من انطلاق المباراة.

## 2) إعلان عام (شعار التطبيق، عرض، بطولات…)

```
ad_totv-banner.jpg                       ← يظهر دائماً حتى تحذفه
ad_until-2026-11-30_offer.jpg            ← يظهر حتى نهاية 30 نوفمبر ثم يختفي
```

## المقاس
- **أفقي 16:9** (مثل 1920×1080 أو 1280×720). أي مقاس أفقي يعمل: الصورة تظهر كاملة بلا قص.
- اجعل الكتابة والوجوه في المنتصف، وابتعد عن الحواف قليلاً.
- الصور الكبيرة تُصغَّر وتُضغط تلقائياً.
