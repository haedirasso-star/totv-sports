# خلاصة مباريات TOTV+ — التشغيل المجاني

ملف واحد `matches.json` يُحدَّث تلقائياً ويقرؤه كل المستخدمين من GitHub Pages.
التطبيق لا يتصل بـ API-Football أبداً، ولا يحتوي أي مفتاح.

## الإعداد (مرة واحدة، 15 دقيقة تقريباً)

1. **أنشئ مستودعاً عاماً (Public)** على GitHub باسم `totv-sports`، وارفع إليه محتوى هذا المجلد كما هو (مع مجلد `.github`).
   - يجب أن يكون المستودع عاماً: دقائق GitHub Actions غير محدودة ومجانية للمستودعات العامة، وGitHub Pages مجاني لها.
   - المفاتيح لا تُكتب في الملفات أبداً، بل في Secrets (الخطوة 3)، فلا يراها أحد.
2. **Settings → Pages → Source = GitHub Actions**
3. **Settings → Secrets and variables → Actions**
   - في **Secrets**:
     - `API_FOOTBALL_KEY`: من dashboard.api-football.com (الخطة المجانية).
     - `GEMINI_API_KEY`: من aistudio.google.com ثم Get API key (مجاني). اختياري، وبدونه تُرسل إشعارات بنص جاهز.
     - `FCM_SERVICE_ACCOUNT`: انسخ محتوى ملف JSON كاملاً. للحصول عليه:
       1. افتح Google Cloud Console لمشروع Firebase نفسه، ثم IAM → Service Accounts → Create.
       2. امنحه دور **Firebase Cloud Messaging API Admin** فقط، ولا تستخدم مفتاح المشروع الكامل.
       3. من Keys اختر Add key ثم JSON.
       4. تأكد أن «Firebase Cloud Messaging API (V1)» مفعّل.
   - في **Variables**:
     - `FEED_URL` = `https://USERNAME.github.io/totv-sports`
4. **Actions → sports-feed → Run workflow** مع تفعيل `test_notify`. يصل إشعار تجريبي لحساب المشرف.
5. افتح `https://USERNAME.github.io/totv-sports` لترى لوحة الحالة: الطلبات المستخدمة، والمباريات، وآخر خطأ.
6. **في Firestore:** في `app_config/remote_config` أضف حقلاً نصياً `sports_feed` = نفس الرابط.
   - يصل الرابط للمستخدمين خلال 6 ساعات كحد أقصى.
   - للتفعيل الفوري ضعه أيضاً في `kSportsFeed` داخل `lib/core/constants.dart` قبل بناء النسخة.

## كيف لا تنفد الـ 100 طلب؟

| المهمة | الطلبات يومياً |
|---|---|
| مباريات الأسبوع (7 أيام × كل الدوريات) **بطلب واحد** يُحدَّث كل 6 ساعات | 4 |
| إن رفض الخادم الطلب الأسبوعي: طلب لكل يوم (اليوم كل 4 س، الغد كل 12 س، البقية مرة) | نحو 13 |
| النتائج والأهداف | **0**، غير مطلوبة |
| الشعارات وألوان الأندية وصور الإشعار | **0**، لا تُحسب |
| المستخدمون (50 ألف أو أكثر) | **0**، يقرؤون الملف المنشور |

- يجرّب الخادم الطلب الأسبوعي الواحد أولاً تلقائياً.
- إن رفضه API-Football (بعض الخطط تشترط الدوري والموسم مع from/to) يتحوّل وحده إلى «يوم بيوم»، ويعيد التجربة أسبوعياً.
- لوحة الحالة تعرض الطريقة المستخدمة حالياً.

## إعلانات المباريات (مجلد promos)

1. افتح مجلد `promos` في المستودع، ثم Add file ← Upload files.
2. سمِّ الصورة بموعد الانطلاق بتوقيت بغداد: `2026-10-20_21-45.jpg` أو `2026-10-20_21-45_ريال-برشلونة.jpg`.
3. تُنشر خلال دقيقة تقريباً، وتظهر في:
   - شريط الإعلانات في الرئيسية مع الأفلام والمسلسلات.
   - أعلى صفحة الرياضة.

- يظهر مع الإعلان عدّاد تنازلي.
- يُربط الإعلان تلقائياً بالمباراة التي تنطلق في الموعد نفسه، فيعمل زر «شاهد» عند بدايتها.
- يختفي الإعلان تلقائياً بعد ساعتين من الانطلاق.

## الإشعارات: صافرة البداية

- عند انطلاق **كل مباراة** في الدوريات المختارة يصل إشعار بصوت صافرة الحكم، مع صورة فيها شعارا الفريقين.
- إذا انطلقت 3 مباريات أو أكثر في نفس الدقيقة يُجمعن في إشعار واحد.
- لا إشعار على الأهداف ولا نتائج.
- Gemini يكتب نص الإشعار بأسلوب المعلّق الحماسي، وإن تعطّل يُرسل نص جاهز.
- الحد الأقصى `maxNotificationsPerDay` في `config.json` (الافتراضي 40).

## القناة الناقلة

- `channels` في `config.json`: كلمات البحث عن القناة في سيرفرك لكل دوري، والأولى لها الأفضلية.
- `overrides`: قناة محددة لمباراة بعينها، بالشكل `{"1234567": "beIN SPORTS 1 HD"}`.
- في التطبيق، عند الضغط على «شاهد»:
  - قناة واحدة تُفتح مباشرة.
  - عدة قنوات تظهر في قائمة اختيار.
  - إن لم توجد قناة مصرّح بها لباقة المستخدم يُنقل إلى «القنوات المباشرة».

## ملاحظات

- جدولة GitHub قد تتأخر بضع دقائق في أوقات الضغط، لذلك قد يصل إشعار الصافرة بعد الانطلاق بدقائق قليلة.
- التطبيق يطلب الملف كل 10 دقائق كحد أقصى، والعدّاد التنازلي يعمل محلياً على الجهاز.
- الحد المرن لـ GitHub Pages هو 100GB شهرياً. التقدير لـ 50 ألف مستخدم بين 15 و45GB، وإن تجاوزته اربط المستودع نفسه بـ Cloudflare Pages (مجاني وبلا حد للنطاق).
- الخطة المجانية لـ API-Football تغطي «المواسم الحديثة». إن ظهر في لوحة الحالة خطأ عن الموسم فهو قيد من الخطة نفسها.
